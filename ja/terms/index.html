第1条（適用）

  1. 本規約は、本サービスのご予約者（以下「お客様」）と当社との間の撮影契約（以下「本契約」）に適用されます。
  2. 撮影に参加される方全員に、本規約の内容をお伝えください。
  3. お客様が未成年の場合は、親権者などの法定代理人の同意を得たうえでご予約ください。
  4. 本規約と、ご予約時に当社がメールなどの書面で個別にお知らせした条件が異なる場合は、その個別の条件が優先します。ただし、ご予約ページや見積書に自動的に表示される一般的な条件は、個別の条件に当たらないものとします。

第2条（ご予約と契約の成立）

  1. お問い合わせフォームやメールなどでご希望の日程とプランをお知らせください。当社がカメラマンの空き状況を確認し、撮影できる場合にご予約ページをご案内します。
  2. ご予約ページで、本規約が本契約の内容となることに同意したうえでお申し込みください。お申し込みと予約金のお支払いが完了し、当社が予約確定のメール（プラン、撮影日時、料金、受領した予約金の額と受領日、当社の名称と連絡先を記載します）を送信した時点で、本規約を内容とする本契約が成立します。
  3. 予約金のお支払いが確認できるまで、撮影日は確保されません。

第3条（プランの内容）

  1. 各プランの料金、撮影時間、人数、撮影場所の数、納品枚数の目安は、お客様がお申し込みになったご予約ページに表示するとおりです（日本語サイトの料金は撮影プランと料金をご覧ください）。納品枚数は目安であり、撮影条件によって前後します。
  2. 撮影エリアは、ニセコエリア（ニセコ町、倶知安町のひらふ・花園、昆布温泉（蘭越町・ニセコ町）を含みます）、小樽、洞爺湖周辺です。これらのエリアへのカメラマンの交通費・出張費は料金に含まれます。
  3. 上記以外の場所での撮影は、事前に当社と合意した場合に限り、別途お見積りする出張費で承ります。
  4. プランに定める人数を超える場合は、ご予約前にご相談ください。事前のご相談なく当日に人数が超えた場合は、プランに定める人数の範囲で撮影します。
  5. 撮影場所までのお客様の移動手段と費用、撮影場所の入場料や施設利用料は、お客様のご負担です。

第4条（料金とお支払い）

  1. 料金は、ご予約ページに表示する金額とし、すべて税込です。
  2. ご予約時に料金の50%を予約金としてお支払いいただきます。残金は撮影当日にお支払いください。お支払い方法は、クレジットカードまたは銀行振込です。
  3. 銀行振込の振込手数料はお客様のご負担となります。
  4. 撮影当日に人数が予定より少なくなった場合や、撮影時間を短くされた場合でも、料金は変わりません。
  5. 当社からの返金は、本規約に別の定めがある場合を除き、返金が確定した日から14日以内に行います。クレジットカードでのお支払いは取消処理により、銀行振込でのお支払いはお客様が指定する口座への振込により返金します。返金時の振込手数料は当社が負担します。
  6. 残金のお支払いが確認できるまで、写真の納品を保留することがあります。

  6. 本サービスは、特定商取引法に定めるクーリング・オフの対象ではありません。

第6条（日程の変更）

  1. ご予約確定後の撮影日の変更は、原則として承っておりません。別の日程をご希望の場合は、元のご予約を第5条に従ってキャンセルしたうえで、新たにご予約（予約金のお支払いを含みます）をお願いします。
  2. ただし、生命に関わる急な病気やけがなど、お客様に責任のないやむを得ない事情がある場合は、個別にご相談のうえ、別の日程への振り替えを検討します。状況を確認できる書類のご提出をお願いすることがあります。自然災害などについては第16条によります。
  3. 同じ撮影日の中での開始時刻の調整は、カメラマンの予定が許す範囲で承ります。

第7条（悪天候時の対応）

  1. 撮影を実施するかどうかは、気象情報、現地の状況、お客様とスタッフの安全をもとに当社が判断します。判断は原則として撮影日の前日18時（日本時間）まで、または当日の撮影開始前にお知らせします。
  2. 小雨、雪、曇り、霧などの場合も、撮影に支障がない限り予定どおり撮影します。雪や霧の中の写真も、北海道らしい旅の記録になります。
  3. 暴風や大雪などの警報が出ている、道路が通行止めになっている、スキー場のリフトが運休しているなど、安全に撮影できないと当社が判断した場合は、お客様のご滞在中の別の時間または日程に無料で振り替えます。
  4. ご滞在中に振り替えができない場合は、お支払い済みの金額を、元の撮影日から12か月間有効のクレジット（次回のご予約に充てられる預り金）としてお預かりします。クレジットはいずれのプランにもご利用いただけます。料金の差額が生じる場合は、ご利用時に精算します。ただし、ご帰国などによりクレジットのご利用が難しい場合は、元の撮影日から30日以内にお申し出いただければ、お支払い済みの金額から事務手数料5,000円を差し引いた額を返金します。
  5. 撮影の途中で天候が急変し、当社が撮影を中止した場合は、撮影できた時間が予定の半分以上であれば、撮影できた写真を納品して撮影は完了したものとします（納品枚数は撮影時間に応じて少なくなります）。この場合、ご滞在中にカメラマンの予定が空いていれば、撮影できなかった時間分の撮影を無料で行います。撮影できた時間が予定の半分未満であれば、第3項および第4項と同様に、振り替えまたはクレジットとします。

第8条（当社都合による中止）

  1. カメラマンの急病やけがなど当社の事情で撮影ができなくなった場合は、当社のチームの別のカメラマンによる代行、またはお客様のご滞在中の別の日程への振り替えをご提案します。
  2. いずれもお客様にご同意いただけない場合や、手配ができない場合は、お支払い済みの金額の全額を返金します。
  3. 当社都合で撮影開始が遅れた場合は、撮影時間を延長して予定の撮影時間を確保します。延長できない場合は、不足した時間の割合に応じて、料金の一部を返金します。

第9条（撮影当日）

  1. 待ち合わせ場所と時刻は、事前にメールなどでご案内します。
  2. お客様の遅刻により撮影開始が遅れた場合でも、撮影は予定の終了時刻に終了し、料金の返金はありません。
  3. 撮影時間の延長は、当日のカメラマンの予定が許す場合に限り、事前にお伝えする料金で承ります。
  4. 撮影の構図、撮影場所の選び方、写真の選定と編集は、ご要望を伺ったうえで、カメラマンの判断で行います。
  5. 安全を確保できない場所での撮影や、法令や施設のルールに反する撮影はお断りします。
  6. お客様が飲酒などにより安全に撮影できない状態にある場合や、カメラマンやガイドへの迷惑行為があった場合は、撮影を中止することがあります。この場合は、撮影当日のキャンセルとして第5条を適用します。

第10条（ニセコ スキー撮影プラン）

  1. 本プランは冬季限定で、プロのスキーガイドが同行します。滑走ルートと撮影場所は、積雪、天候、混雑状況をもとにガイドとカメラマンが決定します。
  2. リフト券はお客様ご自身でご用意ください（料金には含まれません）。
  3. 参加者は、スキー場の中級コースをスキーまたはスノーボードで安全に滑走できる方とします。スキー場のルールやガイドの指示に従っていただけない場合は、安全のため撮影を中止することがあります。この場合、料金の返金はありません。
  4. 撮影はスキー場の管理区域内で行います。管理区域外（バックカントリー）での撮影は行いません。
  5. ヘルメットの着用と、スキーやスノーボード中のけがに対応した保険へのご加入をおすすめします。
  6. 強風などでリフトが運休し撮影できない場合は、第7条に従います。

第11条（写真の納品）

  1. 当社が選定し編集した写真を、撮影日の翌日から5営業日以内に、お客様専用のオンラインギャラリーで納品します。営業日には、土日祝日と年末年始（12月29日から1月3日）を含みません。
  2. 納品する写真は高解像度のJPEGデータです。未編集のデータ（RAWデータ）はお渡ししません。
  3. 色味や明るさなどの標準的な編集は料金に含まれます。体型の補正や写り込んだ人物の消去など、標準を超える加工は承っておりません。
  4. オンラインギャラリーに公開期限は設けていませんが、念のため納品後はお早めにダウンロードして保管してください。サービスの終了などでギャラリーの公開を終了する場合は、30日前までにお知らせします。
  5. 撮影データは納品後1年間保管します。この期間を過ぎた後の再納品はお約束できません。

第12条（著作権と写真のご利用）

  1. 撮影した写真の著作権は当社に帰属します。
  2. お客様と被写体の方は、納品された写真を、プリント、アルバム、SNSへの投稿、ご家族やご友人との共有など、私的な目的で自由にご利用いただけます。私的な目的の範囲でのトリミング、明るさの調整、SNSのフィルターの使用も可能です。SNSへの投稿の際に「Niseko Memories」とご記載いただけると幸いです。
  3. 広告、商品、販売、事業の宣伝など、営利目的でご利用になる場合は、事前に当社の書面（メールを含みます）による承諾が必要です。

第13条（写真の掲載）

  1. お客様は、本規約に同意してご予約いただくことにより、撮影した写真を当社のウェブサイト、SNS（当社アカウントの広告を含みます）および作品集に掲載することに同意したものとします。お客様は、撮影に参加される方（お子さまについては親権者）から、この掲載について了承を得るものとします。
  2. 掲載を希望されない場合は、ご予約時またはその後いつでもメールでお知らせください。掲載済みの写真がある場合は、ご連絡から14日以内に削除します。ただし、すでに配布した印刷物などについては回収できません。
  3. お子さまの顔が分からない写真のみ掲載するなど、掲載方法についてのご希望も承ります。
  4. お客様のお名前などの個人情報は、ご本人の同意なく掲載しません。

第14条（お客様へのお願い）

  1. 撮影中は、お子さまから目を離さないよう、保護者の方がご注意ください。
  2. 貴重品や手荷物の管理はお客様ご自身でお願いします。
  3. ホテルや店舗、私有地などで撮影を希望される場合は、事前に施設の許可を得てください。許可の取り方は当社からもご案内します。
  4. カメラマンやガイドの安全に関する指示には従ってください。
  5. ご予約時の情報（人数、連絡先など）に変更があった場合は、速やかにお知らせください。

第15条（責任の範囲）

  1. 機材の故障やデータの破損など、当社の責任による理由で写真を納品できなかった場合は、お支払い済みの金額の全額を返金します。写真の一部を納品できなかった場合は、納品できなかった割合に応じて返金します。いずれの場合も、ご希望により、可能な範囲で再撮影を無料で承ります。
  2. 本サービスに関して当社がお客様に損害賠償責任を負う場合、その額はお客様が本契約に基づいてお支払いになった金額を上限とします。
  3. ただし、当社の故意または重大な過失による損害、および人の生命または身体に生じた損害については、前項の上限は適用しません。
  4. 撮影中のお客様のけがや持ち物の破損・紛失については、当社（カメラマンおよび当社が手配したガイドを含みます）に故意または過失がある場合を除き、責任を負いません。

第16条（不可抗力）

  1. 地震、噴火、大雪などの自然災害、感染症の流行、交通機関の運休、行政機関の要請など、当社にもお客様にも責任のない事由により撮影ができない場合は、第7条第3項および第4項と同様に、振り替えまたはクレジットとします。
  2. 前項の事由（航空便の欠航など）によりお客様が撮影場所へお越しになれない場合も、同様とします。この場合、状況を確認できる書類のご提出をお願いすることがあります。お客様個人のご病気やけがは、本条ではなく第6条第2項によります。

第17条（反社会的勢力の排除）

  1. お客様と当社は、それぞれ、自らが暴力団、暴力団員、その他これらに準ずる反社会的勢力に該当しないこと、また今後も該当しないことを表明し、保証します。
  2. お客様または当社が前項に違反した場合、相手方は催告なしに本契約を解除できます。

第18条（個人情報の取り扱い）

お客様の個人情報は、プライバシーポリシーに従って取り扱います。

第19条（本規約の変更）

  1. 当社は、民法第548条の4に従い、本規約を変更することがあります。変更する場合は、変更後の内容と効力発生日を、効力発生日より前に本ページでお知らせします。
  2. すでに成立している本契約には、ご予約時点の規約が適用されます。ただし、お客様にとって有利な変更は、すでに成立している本契約にも適用します。

第20条（準拠法と管轄）

  1. 本規約と本契約は、日本法に準拠します。
  2. 本契約に関する紛争については、札幌地方裁判所または札幌簡易裁判所を第一審の専属的合意管轄裁判所とします。ただし、法令によりお客様の住所地の裁判所に訴えを提起できる場合や、法令により本項の合意の効力が制限される場合は、その定めに従います。
