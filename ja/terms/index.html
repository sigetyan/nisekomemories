撮影規約

最終更新：2026年10月29日

この撮影規約（以下「本規約」）は、NOMADO合同会社（以下「当社」）が「Niseko Memories」の名称で提供する出張撮影サービス（以下「本サービス」）について、ご予約からキャンセル、納品までの取り扱いを定めるものです。ご予約の前に必ずお読みください。料金やお支払い方法などについては特定商取引法に基づく表記を、個人情報の取り扱いについてはプライバシーポリシーをご覧ください。

ポイント

  • ご予約時に料金の50%、残金は撮影当日
  • 31日前までのキャンセルは事務手数料5,000円のみ（残りの予約金は返金）
  • 悪天候で安全に撮影できない場合は、ご滞在中に無料で振り替え（できない場合は12か月クレジット、または事務手数料5,000円を差し引いて返金）
  • 写真は原則5営業日以内にオンラインギャラリーで納品

第1条（適用）

  1. 本規約は、本サービスのご予約者（以下「お客様」）と当社との間の撮影契約（以下「本契約」）に適用されます。
  2. 撮影に参加される方全員に、本規約の内容をお伝えください。
  3. お客様が未成年の場合は、親権者などの法定代理人の同意を得たうえでご予約ください。
  4. 本規約と、お客様と当社がメールなどで個別に合意した条件が異なる場合は、その個別の合意が優先します。ご予約ページや見積書に表示された条件と本規約が異なる場合は、お客様に有利な方を適用します。

第2条（ご予約と契約の成立）

  1. お問い合わせフォームやメールなどでご希望の日程とプランをお知らせください。当社がカメラマンの空き状況を確認し、撮影できる場合にご予約ページをご案内します。
  2. ご予約ページで、本規約が本契約の内容となることに同意したうえでお申し込みください。お申し込みと予約金のお支払いが完了し、当社が予約確定のメール（プラン、撮影日時、料金、受領した予約金の額と受領日、当社の名称と連絡先を記載します）を送信した時点で、本契約が成立し、本規約がその内容となります。
  3. 予約金のお支払いが確認できるまで、撮影日は確保されません。予約金のお支払い後に当社がご予約を確定できない場合は、受領した予約金の全額を返金します。

第3条（プランの内容）

  1. 各プランの料金、撮影時間、撮影できる人数、撮影場所の数、納品枚数の目安は、お客様がお申し込みになったご予約ページに表示されたとおりです（撮影プランと料金もご覧ください）。納品枚数は目安であり、撮影条件によって前後します。
  2. 撮影エリアは、ニセコエリア（ニセコ町、倶知安町のひらふ・花園、蘭越町とニセコ町にまたがる昆布温泉を含みます）、小樽、洞爺湖周辺です。これらのエリアへのカメラマンの交通費・出張費は料金に含まれます。
  3. 上記以外の場所での撮影は、事前に当社と合意した場合に限り、別途お見積りする出張費で承ります。
  4. プランに定める人数を超える場合は、ご予約前にご相談ください。事前のご相談なく当日に人数が増えた場合は、プランに定める人数までを撮影します。
  5. 撮影場所までのお客様の移動手段と費用、撮影場所の入場料や施設利用料は、お客様のご負担です。

第4条（料金とお支払い）

  1. 料金は、ご予約ページに表示された金額で、すべて税込です。
  2. ご予約時に料金の50%を予約金としてお支払いいただきます。予約金は料金の一部に充当するもので、民法第557条に定める解約手付ではありません。予約金と残金は、クレジットカードまたは銀行振込でお支払いいただけます。残金は撮影当日に、当社がご案内する方法（クレジットカードの決済リンクまたは銀行振込）でお支払いください。
  3. 銀行振込の振込手数料はお客様のご負担となります。
  4. 撮影当日に人数が予定より少なくなった場合や、撮影時間を短くされた場合でも、料金は変わりません。
  5. 当社からの返金は、本規約に別の定めがある場合を除き、返金が確定した日（キャンセルの場合はキャンセル日、その他の場合は当社が返金をお知らせした日）から14日以内に行います。クレジットカードでのお支払いは取消処理により、銀行振込でのお支払いはお客様が指定する口座への振込により返金します。返金時の振込手数料は当社が負担します。料金と返金はすべて日本円で行います。為替レートの変動による差額や、カード会社・金融機関が課す海外事務手数料・為替手数料は、当社の負担には含まれません。
  6. 残金のお支払いが確認できるまで、写真の納品を保留することがあります。

第6条（日程の変更）

  1. ご予約確定後の撮影日の変更は、原則として承っておりません。別の日程をご希望の場合は、元のご予約を第5条に従ってキャンセルしたうえで、新たにご予約（予約金のお支払いを含みます）をお願いします。
  2. ただし、入院を要する急な病気やけが、ご家族のご不幸など、お客様に責任のないやむを得ない事情がある場合は、個別にご相談のうえ、別の日程への振り替えを検討します。状況を確認できる書類のご提出をお願いすることがあります。ご提出は任意です。ご提出いただいた書類（診断書など、病歴に関する情報が含まれる場合があります）は、ご本人の同意を得たうえで振り替えの判断のためにのみ利用し、判断後に削除します。自然災害などについては第16条によります。
  3. 同じ撮影日の中での開始時刻の調整は、カメラマンの予定が許す範囲で承ります。

第7条（悪天候時の対応）

  1. 撮影を実施するかどうかは、気象情報、現地の状況、お客様とスタッフの安全をもとに当社が判断します。判断の結果は、原則として撮影日の前日18時（日本時間）までに、または当日の撮影開始前に、メールまたはWhatsAppでお知らせします。前日18時までに当社からご連絡がない場合は、予定どおり撮影を行います（当日の天候の急変を除きます）。
  2. 小雨、雪、曇り、霧などの場合も、撮影に支障がない限り予定どおり撮影します。雪や霧の中の写真も、北海道らしい旅の記録になります。
  3. 暴風や大雪などの警報が出ている、道路が通行止めになっている、スキー場のリフトが運休しているなど、安全に撮影できないと当社が判断した場合は、お客様のご滞在中の別の時間または日程に無料で振り替えます。
  4. ご滞在中に振り替えができない場合は、お支払い済みの金額を、元の撮影日から12か月間有効のクレジット（次回のご予約の料金に充当できる権利）に切り替えます。クレジットはどのプランにも使えます。料金に差がある場合は、ご利用時に精算します。クレジットは、元の撮影日から12か月以内の日を撮影日とするご予約にご利用ください。期間内にご利用がない場合、クレジットは失効します。ただし、当社が振り替えできない旨をお知らせした日から30日以内にお申し出いただいた場合は、理由を問わず（ご帰国などでクレジットのご利用が難しい場合など）、クレジットに代えて、お支払い済みの金額から事務手数料5,000円を差し引いた額を返金します。上記の返金の場合を除き、クレジットを現金に払い戻すことはできません。当社は、振り替えできない旨をお知らせするメールで、クレジットと返金のどちらかを選べることと、返金のお申し出の期限をお伝えします。
  5. 撮影の途中で天候が急変し、安全のため当社が撮影を中止した場合は、撮影できた写真を納品します。撮影できなかった時間分は、ご滞在中にカメラマンの予定が空いていれば無料で撮影します。追加の撮影ができない場合は、撮影できなかった時間の割合に応じて、料金の一部を返金します。

第8条（当社都合による中止）

  1. カメラマンの急病やけがなど当社の事情で撮影ができなくなった場合は、当社のチームの別のカメラマンによる代行、またはお客様のご滞在中の別の日程への振り替えをご提案します。
  2. いずれもお客様にご同意いただけない場合や、手配ができない場合は、お支払い済みの金額の全額を返金します。
  3. 当社都合で撮影開始が遅れた場合は、撮影時間を延長して予定の撮影時間を確保します。延長できない場合は、不足した時間の割合に応じて、料金の一部を返金します。

第9条（撮影当日）

  1. 待ち合わせ場所と時刻は、事前にメールまたはWhatsAppでご案内します。当日、遅れそうな場合や待ち合わせ場所が分からない場合は、WhatsApp（+81 90 3399 7122）でご連絡ください。当日に当社からご連絡する場合も、同じ方法で行います。
  2. お客様の遅刻により撮影開始が遅れた場合でも、撮影は予定の終了時刻に終了し、料金の返金はありません。
  3. 撮影時間の延長は、当日のカメラマンの予定が許す場合に限り、事前にお伝えする料金で承ります。
  4. プランに定める数の範囲で決めた撮影場所での構図や立ち位置、写真の選定と編集は、ご要望を伺ったうえで、カメラマンの判断で行います。
  5. 安全を確保できない場所での撮影や、法令や施設のルールに反する撮影はお断りします。
  6. お客様や撮影に参加される方が飲酒などにより安全に撮影できない状態にある場合や、カメラマンやガイドへの迷惑行為があった場合は、撮影を中止することがあります。この場合は、撮影当日のキャンセルとして第5条を適用し、中止までに撮影した写真は納品します。

第10条（ニセコ スキー撮影プラン）

  1. 本プランは冬季限定で、プロのスキーガイドが同行します。滑走ルートと撮影場所は、積雪、天候、混雑状況をもとにガイドとカメラマンが決定します。
  2. リフト券はお客様ご自身でご用意ください（料金には含まれません）。
  3. 参加者は、スキー場の中級コースをスキーまたはスノーボードで安全に滑走できる方とします。当日の滑走の様子から、ガイドの判断でよりやさしいコースに変更して撮影を続けることがあります。スキー場のルールやガイドの指示に従っていただけない場合は、安全のため撮影を中止することがあります。この場合は、撮影当日のキャンセルとして第5条を適用し、中止までに撮影した写真は納品します。
  4. 撮影はスキー場の管理区域内で行います。管理区域外（バックカントリー）での撮影は行いません。
  5. ヘルメットの着用と、スキーやスノーボード中のけがに対応した保険へのご加入をおすすめします。
  6. 強風などでリフトが運休し撮影できない場合は、第7条に従います。

第11条（写真の納品）

  1. 当社が選定し編集した写真を、撮影日の翌日から原則として5営業日以内に、お客様専用のオンラインギャラリーで納品します。撮影内容や繁忙期などにより5営業日を超える場合は、納品予定日をお知らせします。営業日には、土日祝日と年末年始（12月29日から1月3日）を含みません。
  2. 納品する写真は高解像度のJPEGデータです。未編集のデータ（RAWデータ）はお渡ししません。
  3. 色味や明るさなどの標準的な編集は料金に含まれます。体型の補正や写り込んだ人物の消去など、標準を超える加工は承っておりません。
  4. オンラインギャラリーに公開期限は設けていませんが、念のため納品後はお早めにダウンロードして保管してください。サービスの終了などでギャラリーの公開を終了する場合は、30日前までにお知らせします。
  5. 撮影データは納品後1年間保管します。この期間を過ぎた後の再納品はお約束できません。
